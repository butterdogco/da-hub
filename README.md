# Da Hub

Da Hub is a games website, featuring over 100 games.
Note that this version is no longer being updated, and will likely not be updated again anytime soon. Our focus has moved to the improved version, DH-WS, which does not have public source code unfortunately.

## Games

Tons of games are available on the website, ranging from Flash games, NES, msDOS, regular web games, and some well-known titles such as Geometry Dash (a well made recreation, NOT the Scatch version).

## Features

- Tab cloaking using about:blank
- Multiple languages | Supports: Afrikaans, English, Español, and a few other funny languages based off of English
- Mobile support
